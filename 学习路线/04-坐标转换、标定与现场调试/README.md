# 04：坐标转换、标定与现场调试

## 写在最前面

首先恭喜你，学习到这里你已经完成了全部的有关于电赛视觉的模块任务，你应该已经可以用自己的话讲出来什么是特征工程，如何区别、定位、追踪一个目标，你粗略的学完了和队内负责控制队员的核心区别，你已经是一个合格的“软件视觉手”，但是对于得到的特征数据如何帮助你完成题目要求或者说成为队伍整个系统中的一部分任然是你需要学习的部分，纵使你可以把之后的全部内容都推给你的队友去学习解决。

## 为什么这一关放在通信之前

视觉识别出目标不等于已经得到能用于机械的坐标。要做毫米级定位，必须先确认相机画面、镜头矫正、像素到毫米的映射和现场调试界面说的是同一套坐标。否则即使串口和 G-code 都正确，机械也会去错位置。

这一关的产物不是一条固定公式，而是一套可复查的坐标转换依据：标定参数、已知点误差，以及能看到中间结果的 GUI。

## 1. 像素坐标怎样变成毫米坐标

2026 代码使用比例、中心偏移、轴交换和方向符号把像素点映射为机械坐标。先用已知边长的方块求比例，再用多个已知点检查残差。完整过程见[坐标标定](01-坐标标定.md)。

## 2. 相机畸变什么时候会破坏坐标转换

画面中心正确、越到边缘误差越大且呈放射状变化时，不能再只改比例或偏移，应检查镜头畸变。矫正必须在检测和标定之前固定下来；改了矫正强度、分辨率、ROI、相机位置或工作平面高度，都要重新验证坐标。见[相机畸变矫正](02-相机畸变矫正.md)。

## 3. GUI 如何帮助现场定位问题

现场 GUI 不只是展示识别结果。它要让你看到原图、ROI、候选目标、最终坐标和状态，帮助区分问题在采图、识别、畸变、标定还是输出。见[GUI 调试界面](03-GUI调试界面.md)。

## 闯关项目

1. 用 30 mm 标定方块求一次像素比例，再用多个已知点输出残差、RMSE 和最大误差。
2. 在中心和边缘分别检查已知点；若误差呈放射状增大，保存画面并比较矫正前后的结果。
3. 在 GUI 中同时画出 ROI、候选结果、最终坐标和 FPS；触摸按钮时确认屏幕坐标正确映射回图像。

## 做到什么算过关

你能说明当前毫米坐标建立在哪个分辨率、ROI、镜头矫正和相机安装条件上；能用已知点区分比例、方向和畸变问题；现场异常时，能从界面看到错误最早出现在哪一步。
