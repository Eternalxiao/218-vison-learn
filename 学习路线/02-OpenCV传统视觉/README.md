# 02：OpenCV 传统视觉与特征工程

## 为什么学

MaixPy 的封装接口可以快速完成取图、找色块和常见图像处理，但这只是函数的调用，调用函数之前仍要知道自己在解决什么问题。我们称原图像为`脏数据`,在这阶段你学习的是对原图像的处理，将二值图里出现噪点、孔洞、断裂或粘连消除的方法。

本阶段先用 OpenCV 在电脑上拆开并观察传统视觉处理链，再把已经理解的操作迁移到 MaixCAM Pro。OpenCV 负责帮助你看清机制和中间结果；MaixPy 负责在设备上用封装接口完成同类处理，并尽量避免不必要的 OpenCV 转换与 CPU 开销。

## 学习前需要会什么

- 能运行 Python 脚本并安装 `numpy`、`opencv-python`。
- 已经在 MaixCAM Pro 上用 MaixPy 完成取图、显示和一次基础检测。
- 能保存一张失败图片，而不是只对着实时画面描述“有时能识别”。

## 请按这个顺序阅读

1. [滤波、形态学与轮廓](01-滤波、形态学与轮廓.md)：先在 OpenCV 中理解滤波解决的像素波动、形态学解决的二值区域缺陷，以及轮廓怎样把前景变成可筛选候选。
2. [MaixPy 图像处理接口](02-MaixPy图像处理接口.md)：默认已经掌握第一篇的概念，只学习 MaixPy 的函数、参数差异、原地修改、`find_blobs()` 和 MaixCAM 上的性能取舍。

不要倒过来读。第二篇不会重复解释为什么选择高斯、中值、腐蚀或闭运算；如果还不能从中间图说出选择理由，应先回到第一篇完成静态图片实验。

## 本阶段要看懂的数据流

```text
原始图像 → 颜色或灰度表达 → 滤波 → 阈值分割 → 形态学 → 轮廓或色块 → 特征筛选
```

这是一条排错顺序，不是必须全部执行的模板。每一步都可能改变后面的面积、边界和角点。正确做法是保存中间图，从左向右寻找第一处错误，再只修改对应阶段。

还要注意颜色格式：OpenCV 读入彩色图像通常使用 BGR 顺序，MaixPy 的 `FMT_RGB888` 使用 RGB 存储，而 MaixPy 的颜色阈值按 LAB 范围填写。程序能运行不代表颜色顺序正确；迁移阈值前必须先确认当前图像格式。

## 配套练习与工具

- 使用[特征处理链示例](../../配套资源/示例代码/opencv/README.md)处理一张静态图片，并保存原图、滤波图、二值图、形态学结果、轮廓图和最终结果。
- 使用[离线视觉流程调试器](../../配套资源/工具/视觉流程调试器/README.md)并排比较不同阈值和形态学阶段。
- 在 MaixCAM Pro 上使用[找色块最小例程](../../配套资源/示例代码/maixpy/find_color_blocks.py)，再把自己在 OpenCV 中确认过的处理步骤逐个迁移过去。

## 做到什么算过关

面对一个新的简单目标，你能说明选择了什么视觉特征，为什么需要当前处理步骤；结果失败时，能根据保存的中间图判断问题来自采图与颜色、滤波、阈值、形态学，还是候选筛选；在 MaixCAM 上能优先使用已有 MaixPy 接口，并用实测耗时决定是否需要 OpenCV 或更底层实现。
