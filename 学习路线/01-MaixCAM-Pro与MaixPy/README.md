# 01：MaixCAM Pro 与 MaixPy

## 为什么学

这一关先建立“代码能在设备上连续运行”的闭环。目标不是研究算法内部，而是学会取图、调用检测函数、画调试信息和观察帧率。

## 先想清楚设备：为什么是 MaixCAM Pro

被"买 OpenMV、K230 开发板还是树莓派"这个问题卡住时，先读[为什么选 MaixCAM：主流视觉设备对比](01-为什么选MaixCAM-主流视觉设备对比.md)。它分清成品视觉模块、芯片开发板和"树莓派+摄像头"自建系统三种形态，说明 MaixCAM 系列的主控是算能 SG2002，以及为什么说它是当前完整视觉产品里我最强的选择。

## 学习前需要会什么

- 完成[认识电赛视觉](../00-认识电赛视觉/README.md)。
- 会修改变量、列表、函数参数和 `if` 判断。
- 准备 MaixCAM Pro、数据线和可用存储卡。

## 安装与最小闭环

1. 按官方说明准备 MaixCAM Pro 系统。
2. 安装 MaixVision，并确认电脑能够连接设备。
3. 在 MaixVision 中运行一个摄像头取图程序。
4. 在画面上绘制文字，确认代码、摄像头和显示都正常。
5. 再加入一个检测函数，不要一次复制完整比赛工程。

## 这一阶段学哪些内容

- `camera`：创建摄像头、设置分辨率、读取图像。
- `display`：显示图像和调试标记。
- `image`：颜色阈值、色块、直线、矩形、圆、二维码和 AprilTag 等封装功能。
- `app`：判断程序是否退出，避免写成无法正常停止的死循环。
- `uart`：先知道如何发送视觉结果，协议设计放到第 4 关。
- ROI、阈值、像素数量、面积、合并目标和 FPS。

你需要精读 [MaixPy 快速开始](https://wiki.sipeed.com/maixpy/doc/zh/index.html) 中的重点内容，使用 MaixPy 进行视觉开发，理解大多数需要用到的示例代码。部分常用的示例代码需要学会自己编程、修改[MaixPy 示例代码目录](../../配套资源/示例代码/maixpy/README.md)。这些代码需要在 MaixCAM Pro 上运行，电脑端语法检查不能代替硬件验证。

## 闯关项目

让摄像头持续检测一个颜色块：

1. 每帧读取图像。
2. 在限定 ROI 内调用找色块函数。
3. 过滤过小的结果。
4. 画出边界框和中心点。
5. 显示中心坐标和 FPS。
6. 把阈值和 ROI 改成另一个场景，再运行一次。

## 做到什么算过关

你可以读懂完整demo代码，能够独立查到需要用的 API，完成取图、检测和可视化；结果错误时，能先检查输入、ROI、阈值和过滤条件。

## 实际调试经验

- 先画 ROI 和所有候选结果，再加入复杂筛选，否则很难知道目标在哪一步被过滤掉。
- 分辨率变小通常会提高速度，但面积、距离和坐标参数也会一起变化。
- 自动曝光变化会让颜色阈值漂移。比赛环境固定后，应重新采图并验证阈值。
- 同一颜色可能跨越多个范围，阈值应保存为二维列表，而不是只能填一组数。
