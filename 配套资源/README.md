# 配套资源

这里保存学习路线直接使用的代码、模型示例、工具和历年题目参考实现。

- [示例代码](示例代码/README.md)：MaixPy、OpenCV、YOLO11、通信与 G-code。
- [模型](模型/README.md)：一组 `.mud + .cvimodel` 和板端推理示例。
- [视觉流程调试器](工具/视觉流程调试器/README.md)：离线观察每个图像处理阶段。
- [历年题目参考代码](历年题目参考代码/README.md)：2021、2023、2024、2025、2026 代码归档。

示例代码与历年完整工程的用途不同：示例代码尽量小、参数明确，适合跟着学习；历年代码保留了实际组织方式和历史个人组织痕迹不建议直接使用，只作为掌握基础后参考。
