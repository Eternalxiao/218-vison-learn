# 离线视觉流程调试器

双击 `index.html` 即可打开。首次加载本地 `opencv.js` 需要几秒，页面顶部显示“OpenCV.js 已就绪”后再处理图片。工具不上传图片，也不需要网络。

本工具是为了帮助理解滤波以及心态学处理的各个阶段，不需要借助实际的视觉设备，通过对静态图片的操作观看每一个步骤后、每一组参数被增加后图片会发生什么样的变化。

## 能做什么

- 上传自己的图片，或生成一张内置彩色图形样例。
- 选择 Gray、HSV 或 LAB。
- 使用多组范围、固定阈值、Otsu 或自适应阈值。
- 调整高斯/中值滤波、腐蚀、膨胀、开运算和闭运算。
- 同时观察原图、颜色空间、滤波、二值化、每个形态学阶段和轮廓。
- 下载任一阶段的 PNG。
- 导入、导出 JSON 参数。
- 把多范围重排为 MaixPy 常见的 `[min1,max1,min2,max2,min3,max3]` 列表。

## 数值范围

- HSV：H 为 0～179，S/V 为 0～255。
- LAB：界面使用 MaixPy 常见范围，L 为 0～100，A/B 为 -128～127；处理时会转换到 OpenCV 的 8 位 LAB 表示。
- Gray：多范围模式只使用第一通道的最小值和最大值。

复制出的阈值在格式上可直接使用，但摄像头颜色、曝光和设备实现会影响数值，仍应在 MaixCAM Pro 实际画面中复核。

## 推荐调试顺序

1. 先选颜色空间并观察原图。
2. 只启用阈值，确认前景是否被选中。
3. 再加入一种滤波。
4. 依次调整腐蚀、膨胀、开运算和闭运算。
5. 最后根据轮廓面积过滤候选。

每次只改一类参数。哪个阶段第一次把正确目标破坏掉，就回到那个阶段处理。
