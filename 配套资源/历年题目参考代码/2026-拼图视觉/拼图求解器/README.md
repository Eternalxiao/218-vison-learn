# 拼图求解器代码阅读说明

本目录保存 2026 拼图任务中形成的 Python 求解代码、MaixCAM 集成尝试和 C++ 实验源码。公开它的目的，是展示视觉轮廓如何转换成求解器输入，以及求解结果如何返回放置变换。

## 主要文件

- `puzzle_solver.py`：以碎片顶点为输入的 Python 求解入口。
- `embedded_puzzle_solver.py`：面向设备端约束的实现尝试。
- `assembler.py`：拼接结果和放置关系组织。
- `maixcam_integration.py`：视觉输出与求解器之间的适配。
- `solve_test.py`：PC 端调用示例。
- `cpp_source/`：C++ 版本源码和 Python 接口实验。

## 阅读边界

这些文件包含开发阶段的多条路线，接口和依赖并未统一。先运行 `solve_test.py` 理解输入输出，再选择一个实现阅读；不要把所有求解器同时接入主程序。

目录只记录已经留下代码的方案，不宣称 C++ 版本或所有回退分支都已在当前硬件上完成验证。
