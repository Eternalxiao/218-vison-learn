# 2021 送药小车参考代码

## 身份说明

这是备赛阶段整理的 2021 往年题目代码。

## 可以观察什么

- `main.py`：YOLO11 数字检测、HSV 多组阈值和路口区域判断如何进入同一循环。
- `MyOpenCV.py`：MaixPy 图像与 OpenCV 处理的早期封装。
- `MyGetPixel.py`：从图像采样并保存阈值的交互思路。
- `MySendThread.py`：视觉结果异步发送的组织方式。
- `constants.py`：ROI、阈值和状态参数集中管理。

## 运行限制

代码依赖对应时期的 MaixPy 环境、模型文件和现场阈值。目录中的 `.mud` 只描述模型，不包含它引用的全部模型数据，因此不能认为下载后可直接完成推理。

建议先从学习路线中的[MaixCAM Pro 与 MaixPy](../../../学习路线/01-MaixCAM-Pro与MaixPy/README.md)和[串口数据格式](../../../学习路线/05-数据传输、G-code与系统协同/01-串口数据格式.md)开始，再把本目录当作完整程序阅读材料。
