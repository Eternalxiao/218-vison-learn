# 历年题目参考代码

这里把备赛过程中整理的往年题目代码和 2025、2026 实际视觉工程放在同一入口，方便按任务查看不同阶段的写法。

- [2021 送药小车](2021-送药小车/README.md)：神经网络数字识别、HSV 多阈值、路口视觉判断和串口发送。
- [2023 自动追踪](2023-自动追踪/README.md)：激光点检测、色块过滤、帧差和坐标发送。
- [2024 三子棋](2024-三子棋/README.md)：棋盘定位、棋子检测、网格排序和不同数据格式。
- [2025 TI 杯视觉](2025-TI杯视觉/README.md)：MaixCAM 形状识别、重叠矩形判断和标定管理。
- [2026 拼图视觉](2026-拼图视觉/README.md)：碎片视觉提取、求解输入输出、坐标映射、G-code 和发送节流。

## 来源边界

2021、2023、2024 是备赛时收集、整理和运行过的往年题目参考代码，并非本人当年的参赛经历。文件保留了原来的实验性写法、参数和设备依赖，只用于学习思路。

2025、2026 是本人参与期间的视觉侧代码。这里不介绍成绩，也不推测控制端内部实现。

## 阅读顺序

先看每个目录的 README，再从 `main.py` 沿着图像输入、检测、筛选和输出调用阅读。历史工程不等同于推荐模板：其中的绝对设备路径、旧 API、现场参数和未完成分支需要根据当前环境调整。
