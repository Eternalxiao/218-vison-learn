# 2023 自动追踪参考代码

## 身份说明

这是备赛阶段整理的 2023 往年题目代码。目录里同时保留了当时的工程版和一条单文件算法实验路线，供对照阅读。

## 可以观察什么

完整工程（MaixPy 应用 `laseltrack`，见 `app.yaml`）：

- `main.py`：主入口。角点扫描由下位机发来的 `scan` 指令触发，扫不满 4 个角点就把指令塞回队列重试；激光点逐帧检测；两者合并成一帧数据发送。
- `look_for_data.py`：角点检测取 `RETR_TREE` 轮廓树的最外层和最内层四边形，对应顶点求平均作为最终角点；激光点用帧差法提取变化区域，再按颜色区分红绿并取质心。
- `MyOpenCV.py`：MaixPy 图像与 OpenCV 之间的格式转换封装，中值滤波加高斯滤波、闭运算，以及按图像中位数自适应的双阈值 Canny。
- `my_utils.py`：串口在构造时初始化一次。提供 JSON 明文和二进制帧两种发送格式，二进制帧有帧头（角点 `0xD1D2`、激光点 `0xE1E2`）、大端坐标和帧尾 `0xFEFF`；接收侧通过回调挂接。
- `MyUI.py`：触屏按钮与中文字体加载的简单 GUI。
- `MyGetPixel.py`、`constants.py`：现场采样像素并做 RGB 转 LAB，用于标定颜色阈值和坐标误差。
- `laser.py`、`edged.py`：激光点与边缘检测的独立实验脚本，与主流程并行存在，不是入口。
- `app.yaml`、`app.png`、`dist/`：MaixPy 应用打包配置与 4 个历史版本包，可回看参数和协议的演变过程。

单文件算法实验：

- `单一算法算法试验实现.py`：同一任务的备选路线。不依赖 OpenCV，用 `find_blobs` 找最大黑色色块并放大 120% 作 ROI，`find_rects` 在其中找外矩形，再在缩小 95% 的区域内找内矩形，取内外矩形对应顶点的中点作为四个角点；用连续帧稳定判定和历史平均抑制抖动，激光点带手写的卡尔曼滤波，并在检测激光与检测矩形之间切换相机曝光。串口改用 `@@…#` 定长 ASCII 帧，首帧发全量数据、后续只发激光坐标。与正式工程对照，可以看到同一任务在 OpenCV 轮廓路线和 MaixPy 原生色块路线之间的取舍。

## 运行限制

阈值、面积和坐标都与当时画面有关，不能直接复制到新环境。部分文件是并行实验版本，不应同时作为入口。两个实现的数据格式互不兼容（JSON 与二进制帧对 ASCII 帧），对接下位机时需要先确认协议。阅读时应比较它们的图像输入、阈值、筛选和输出差异。

先完成[OpenCV 传统视觉](../../../学习路线/02-OpenCV传统视觉/README.md)，再用本目录练习定位处理链中的失败阶段；串口部分可配合[串口数据格式](../../../学习路线/05-数据传输、G-code与系统协同/01-串口数据格式.md)阅读。
